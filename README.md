# SpencerCube

A 2x2 Rubik's cube solver. 
The backend is Python and solves the cube optimally with BFS and A*. 
A web front end (HTML, CSS, JS) 
3x3 with IDA* is my stretch goal.

## Layout

```
backend/
  cube.py          cube model, input validation and color normalization, integer encoding, move tables
  solver.py        BFS (baseline), A* with a corner count heuristic, A* with pattern databases
  prepare_data.py  enumerates all 3,674,160 states, saves depth stats and test sets
  evaluate.py      runs every solver on every test case, checks against ground truth
  make_charts.py   figures for the report
  main.py          terminal demo of the full pipeline
  test_cube.py     unit tests for the cube model
data/              generated by prepare_data.py (gods_table.npy is about 3.6 MB)
results/           generated by evaluate.py and make_charts.py
```

## Run it

Needs Python 3.10+ and NumPy (matplotlib for the charts).

```
cd backend
python test_cube.py
python prepare_data.py
python main.py --scramble "R U2 F' R U F2 R' U'"
python main.py --stickers "WROWBGGOBRBRYWYYGWORYOGB" --algorithm bfs
python evaluate.py
python make_charts.py
```

Sticker input is 24 colors, 4 per face, faces in the order U R F D L B, each face read left
to right, top to bottom. Any 6 letters work as colors.

## Moves

The down back left corner stays fixed, so the solver only uses U, R and F turns:
`U U2 U' R R2 R' F F2 F'`. Every move counts as 1 (half turn metric).
